# IPL-Match-Analytics-Dashboard
This dashboard analyzes player performance using key metrics like runs, strike rate, wickets, and economy. It uses charts such as pie and line graphs for clear visualization. It helps compare players efficiently. It highlights top performers. It provides quick insights into overall performance.

📊 IPL 2025 Dashboard

This project presents an interactive IPL 2025 Dashboard built to analyze and visualize key insights from the tournament data. The dashboard helps users explore team performance, player statistics, match outcomes, and trends in an easy and visually appealing way.

🚀 Features
📈 Team Performance Analysis – Wins, losses, and overall standings
🏏 Player Statistics – Top scorers, best bowlers, strike rates
🎯 Match Insights – Toss impact, win margins, venue analysis
📊 Interactive Visualizations – Filters, charts, and dynamic views
📍 Venue-Based Analysis – Performance across different stadiums
🛠️ Tools & Technologies Used
Microsoft Excel / Power BI / Tableau (jo bhi tumne use kiya ho)
Data Cleaning & Transformation
Data Visualization Techniques
